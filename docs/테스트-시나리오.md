### 서버 응답 직접 확인 (선택)

브라우저 주소창이 아닌 터미널에서 확인할 수 있습니다.

```bash
# 빈 입력 → 400 EMPTY_INPUT
curl -X POST https://<배포주소>/api/routine \
  -H "Content-Type: application/json" -d "{\"tasks\":\"\"}"

# 허용되지 않은 시간 값 → 400 INVALID_INPUT
curl -X POST https://<배포주소>/api/routine \
  -H "Content-Type: application/json" -d "{\"tasks\":\"서론 초안 쓰기\",\"minutes\":77}"

# GET 요청 → 405
curl https://<배포주소>/api/routine

# 환경 변수 설정 확인 → ai_configured
curl https://<배포주소>/api/health
```

## E. 로컬 사전 검증 결과 (개발 중 수행함)

배포 전에 로컬(`python dev_server.py`)에서 아래를 검증했습니다.

### E-1. 서버 로직 단위 검증

| 대상 | 검증 내용 | 결과 |
| --- | --- | --- |
| `validate()` | 빈 입력/2자/301자/허용 밖 시간·컨디션/비-JSON 본문 → 각각 지정된 오류 코드 반환 | 통과 |
| `parse_start_time()` | `"99:99"` 등 잘못된 시각 → 현재 시각(KST)으로 대체 | 통과 |
| `extract_json()` | 코드블록(```json```)·설명문이 섞인 응답에서 JSON만 추출 | 통과 |
| `normalize()` | 소요 시간 합이 총 시간 초과 시 잘라내기 / 마지막 휴식 블록 제거 / 필수 필드 누락 시 기본값 | 통과 |
| `normalize()` | `23:30 + 60분 = 00:30` 자정 넘김 계산 | 통과 |
| `check_rate_limit()` | 1분 8회 초과 시 429 | 통과 |
| `classify_upstream()` | 401/403→AUTH, 429→QUOTA, 4xx·5xx→ERROR | 통과 |

### E-2. AI 호출 경로 검증 (응답을 가짜로 주입)

| 대상 | 검증 내용 | 결과 |
| --- | --- | --- |
| OpenAI 경로 | `Authorization: Bearer` 헤더 사용, `response_format: json_object` 지정 | 통과 |
| Gemini 경로 | `x-goog-api-key` 헤더 사용, `responseMimeType` 지정 | 통과 |
| **키 노출 검사** | 요청 URL·본문 어디에도 키 문자열이 포함되지 않음 | 통과 |
| 제공자 선택 | 두 키가 모두 있으면 OpenAI 우선 | 통과 |
| 오류 매핑 | 401/403→502, 429→429, 5xx→502, Timeout→504 | 통과 |
| 이상 응답 | 구조가 다른 JSON / JSON이 아닌 본문 / 설명문만 온 경우 → PARSE_ERROR | 통과 |
